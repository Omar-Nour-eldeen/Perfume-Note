🌸 Perfume Note

«A Modern E-Commerce Platform for a Seamless Perfume Shopping Experience»

Perfume Note is a modern and responsive perfume e-commerce platform designed to provide a simple, elegant, and fast shopping experience.

The platform allows customers to browse perfumes, explore detailed product information, view available images and ingredients, and place orders easily.

It also includes a dedicated Admin Dashboard that allows store administrators to manage products, prices, inventory, orders, and order statuses without modifying the source code.

---

✨ Features

🛍️ Customer Experience

- Modern and responsive design for mobile, tablet, and desktop.
- Browse perfumes in an organized and user-friendly catalog.
- Detailed product pages.
- Multiple product images.
- Display perfume ingredients by:
  - Top Notes
  - Heart Notes
  - Base Notes
- Product availability and pricing.
- Easy product ordering.
- Arabic and English language support.
- Order cancellation based on the current order status.
- Return and refund request system.
- Store notifications for important updates.

🔐 Admin Dashboard

The admin dashboard provides tools for managing the store without changing the source code.

- Product management.
- Add, edit, and delete products.
- Manage product prices.
- Manage inventory and stock availability.
- Manage product images.
- Manage perfume notes and ingredients.
- View and manage customer orders.
- Update order statuses.
- Handle order cancellation requests.
- Manage return and refund requests.
- Receive notifications for important store events.

---

📱 Progressive Web App

Perfume Note is built as a Progressive Web App (PWA), allowing customers to install the website on supported devices and use it like a native application.

PWA Features

- Installable on supported devices.
- App-like user experience.
- Responsive interface.
- Optimized for mobile usage.
- Web-based application without requiring a traditional app-store installation.

---

🔔 Push Notifications

The platform supports Push Notifications to keep users informed about important updates.

Notifications can be used for events such as:

- New order updates.
- Order status changes.
- Important store notifications.
- Other future customer-related events.
